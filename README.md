# Tech Market Web Scraping: Data Science Job Demands in Germany

An automated web data extraction, statistical aggregation, and market visualization pipeline parsing unstructured vacancy frameworks within primary German technology sectors.

## Project Overview
This project simulates a real-world web scraping operations pipeline targeting information science and engineering positions in major German metropolitan hubs (München, Berlin, Frankfurt). The objective is to parse raw web architecture data using BeautifulSoup, engineer location-based financial metrics, and deploy matrix transformations to evaluate industrial hiring trends.

## Tech Stack and Skills Demonstrated
* Python: Functional data pipeline design, string text extraction, and loop integration
* Beautiful Soup (bs4): Unstructured HTML structural parsing, document navigation, and class-tag isolation
* Pandas: Multi-dimensional dataframe generation, advanced categorical grouping, and matrix Transpose (.T) operations
* Matplotlib: Industrial presentation layout styling, vertical bar chart plotting, and visual grid optimization

## Analytical and Data Pipeline
1. Web Scraping Simulation: Automated the textual extraction of technical roles, companies, city branches, and base salaries from unstructured document structures.
2. Data Aggregation and Engineering: Handled individual records to calculate the dynamic average monthly technology salary across distinct target geographical locations.
3. Matrix Transformation (.T): Applied a horizontal matrix transposition to flip the statistical coordinates for an optimized presentation-ready dataframe view.
4. Visual Market Analysis: Manufactured a streamlined visual layout mapping top tech-hub salary brackets to isolate the highest-earning regional economic zones.

## Final Extracted Market Insights
The automated pipeline successfully structures raw digital footprints, revealing strategic distribution baselines for tech career planning in Germany:
* München (Munich): Emerges as the highest-paying economic sector, heavily anchored by AI and automotive industrial frameworks.
* Berlin: Demonstrates strong, continuous demand driven by robust tech-startup ecosystems and machine learning integration.
* Frankfurt: Holds a stable baseline representing highly regulated enterprise banking data operations and cloud infrastructure sectors.
